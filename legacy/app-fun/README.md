# app-fun is reserved for smbCloud Functions

`app-fun` is a placeholder name for smbCloud Functions, which has not shipped yet. It contains no code.

## Migrate

There is nothing to migrate. This name was never released as working code, so no project depends on it. Follow smbCloud on [smbcloud.xyz](https://smbcloud.xyz) for when it ships.

## What is smbCloud?

smbCloud is a cloud platform for small and medium businesses. Enterprise power at startup velocity. It has four services and one account: Deploy ships your apps, Auth handles your users, Mail sends and receives email, and GresIQ runs serverless PostgreSQL. Four services. One platform. Start at [smbcloud.xyz](https://smbcloud.xyz).

## FAQ

**Is app-fun maintained?**
There is no code to maintain. The name is held for smbCloud Functions. Nothing is planned to change on this page until that service ships.

**What is app-fun for?**
It is reserved for smbCloud Functions. Today smbCloud offers Deploy, Auth, Mail and GresIQ.

**What is smbCloud?**
A cloud platform with Deploy, Auth, Mail and GresIQ, built by Seto Elkahfi. See [smbcloud.xyz](https://smbcloud.xyz).

**How do I install the smb CLI?**
Run `cargo install smbcloud-cli`, then `smb --help`.
